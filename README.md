# Вторресурс — лендинг и прайс приёма лома (Омск)

Серверное приложение на Node.js + Express + EJS. Обе страницы рендерятся на сервере
(важно для SEO), прайс хранится в JSON и правится через слой `src/lib/store.js` —
это задел под админку управления ценами.

**Продакшен:** [mbaza55.ru](https://mbaza55.ru) (пока по IP — `http://77.91.112.185`,
до настройки DNS и выпуска сертификата).
Развёртывание, доступы и эксплуатация — в [docs/DEPLOY.md](docs/DEPLOY.md).
Выкатка обновлений: `ssh mbaza55 mbaza55-deploy`.

## Запуск

```bash
npm install
npm start
```

Дев-режим с автоперезапуском:

```bash
npm run dev
```

Приложение поднимается на `http://localhost:3000`. Переменные окружения:

| Переменная  | Назначение                                          | По умолчанию            |
|-------------|-----------------------------------------------------|-------------------------|
| `PORT`      | порт                                                 | `3000`                  |
| `HOST`      | интерфейс                                            | `0.0.0.0`               |
| `SITE_URL`  | боевой адрес — идёт в canonical, OG, sitemap, JSON-LD | `https://vtorresurs55.ru` |
| `NODE_ENV`  | `production` включает кэш статики на 30 дней          | —                       |

## Структура

```
server.js                — точка входа
src/app.js               — express-приложение, middleware, обработка 404/500
src/config/site.js       — контакты, адрес, режим работы, SEO-умолчания
src/content/index.js     — тексты лендинга: преимущества, шаги, услуги, FAQ, витрины
src/lib/store.js         — доступ к прайсу и заявкам (чтение + запись)
src/lib/format.js        — форматирование цен и дат
src/lib/seo.js           — сборка JSON-LD (LocalBusiness, FAQPage, OfferCatalog, крошки)
src/routes/pages.js      — роуты: /, /price, /lead, robots.txt, sitemap.xml
views/                   — EJS-шаблоны
public/                  — CSS, JS, SVG-графика
data/prices.json         — прайс (единственный источник цен)
data/leads.json          — заявки с форм
data/_source/            — исходные выгрузки f-vm.ru, из которых собран прайс
scripts/                 — разовые скрипты импорта прайса
```

## Прайс

`data/prices.json` — две группы (`chermet`, `cvetmet`), 22 категории, 141 позиция.
Структура позиции:

```json
{
  "id": "lom-medi-blesk",
  "title": "Лом меди «Блеск»",
  "note": "механически разделанный кабель, не окисленный…",
  "cash": 818.18,
  "cashTo": null,
  "bank": 900,
  "text": null
}
```

- `cash` — наличный расчёт (для чёрного лома — цена за тонну);
- `cashTo` — верхняя граница диапазона (`20 000 – 30 000`);
- `bank` — безналичный расчёт, показывается только для цветного лома;
- `text` — текстовая цена вместо числовой («до 40 000»), имеет приоритет.

Данные импортированы с [f-vm.ru/price](https://f-vm.ru/price/) и
[f-vm.ru/price_chermet](https://f-vm.ru/price_chermet/). Пересобрать из исходников:

```bash
node scripts/parse-source.js && node scripts/build-prices.js
```

⚠️ Пересборка перезаписывает `data/prices.json` целиком — после запуска админки
скрипты нужны только для разовых массовых импортов.

## Админка (следующий шаг)

Всё уже подготовлено:

1. `src/lib/store.js` содержит `updateItem(groupId, categoryId, itemId, patch)`,
   `replacePrices(data)` и `getLeads(limit)` — запись атомарная (через временный файл),
   кэш сбрасывается автоматически.
2. В `src/app.js` есть закомментированная строка подключения роутера:
   `app.use('/admin', require('./routes/admin'))`.
3. `/admin` уже закрыт в `robots.txt`.

Останется добавить `src/routes/admin.js` (авторизация + форма редактирования цен) и
шаблон `views/admin/*.ejs`. Для аутентификации достаточно `express-session` с одним
логином из переменных окружения либо basic-auth.

## SEO

- серверный рендеринг, уникальные `title`/`description`, `canonical`, OG/Twitter;
- по одному `<h1>` на страницу, семантическая иерархия заголовков;
- JSON-LD: `LocalBusiness`+`RecyclingCenter`, `WebSite`, `WebPage`, `FAQPage`,
  `BreadcrumbList`, `OfferCatalog` со 139 офферами;
- `/robots.txt` и `/sitemap.xml` генерируются на лету, `lastmod` берётся из даты прайса;
- прайс — обычные HTML-таблицы, поиск фильтрует уже отрендеренный DOM,
  поэтому весь контент виден поисковикам без JS;
- страницы работают без JavaScript: форма уходит обычным POST с редиректом.
